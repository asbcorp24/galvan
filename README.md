# GalvaControl — ESP32 система управления линией гальваники

**GalvaControl** — прототип контроллера для автоматизации гальванической линии на базе ESP32. Контроллер управляет перемещением каретки/моста по оси **X**, подъёмом и опусканием подвеса по оси **Z**, выдержкой детали в ваннах, сушкой, вращением, хранением технологических рецептов и привязкой RFID/NFC-меток к ваннам и уровням.

Проект рассчитан на использование с ESP32-WROOM / ESP32 DevKit V1 и собирается в **PlatformIO** под Arduino framework.

---

## 1. Назначение проекта

Система предназначена для автоматизации технологического цикла гальванической обработки:

1. возврат каретки в стартовую точку;
2. определение положения по RFID/NFC-меткам;
3. перемещение к нужной технологической ванне;
4. опускание подвеса на заданный уровень по Z;
5. выдержка детали в растворе;
6. включение вращения при необходимости;
7. подъём подвеса;
8. сушка с вентилятором;
9. переход к следующему шагу рецепта;
10. возврат домой после завершения цикла.

Система имеет локальную веб-панель, OLED-экран, физическую кнопку старта, энкодер меню, аварийный стоп и хранение настроек в NVS-памяти ESP32.

## 2. Основная технология работы

Линия строится на разметке RFID/NFC-метками.

### Ось X — перемещение между ваннами

На линии размещаются RFID-метки:

- стартовая сервисная точка;
- конечная сервисная точка;
- рабочие ванны;
- при необходимости дополнительные сервисные точки.

Контроллер двигает мост по X через реле направления:

- `REL_X_FWD` — движение вперёд;
- `REL_X_REV` — движение назад.

PN532-считыватель по оси X считывает метки. Когда найден UID, контроллер сравнивает его с таблицей ванн в NVS и понимает, где находится каретка.

### Ось Z — уровни подъёма/опускания

Для вертикального перемещения используется второй PN532-считыватель. Он определяет уровни Z по отдельным меткам:

- стартовый уровень Z;
- конечный уровень Z;
- промежуточные уровни опускания/подъёма.

Рецепт может задавать не просто время движения вниз/вверх, а целевые уровни:

- `z_level_down` — уровень, до которого нужно опустить подвес;
- `z_down_timeout_s` — максимальное время опускания;
- `z_level_up` — уровень, до которого нужно поднять подвес;
- `z_up_timeout_s` — максимальное время подъёма.

### Рецепты

Рецепт — это список шагов. Каждый шаг описывает:

- номер ванны;
- уровень опускания Z;
- таймаут опускания;
- время выдержки;
- уровень подъёма Z;
- таймаут подъёма;
- время сушки;
- включать ли вращение;
- включать ли вентилятор.

Рецепты хранятся во flash-памяти ESP32 через `Preferences` / NVS.

## 4. Пиновка ESP32

> В таблице указана пиновка из текущего `src/main.cpp`.

### I2C и OLED

| Устройство | Назначение | GPIO |
|---|---:|---:|
| I2C SDA | шина данных | GPIO21 |
| I2C SCL | шина тактирования | GPIO22 |
| OLED SSD1306 | адрес дисплея | `0x3C` |

### RTC DS1302

| DS1302 | GPIO ESP32 |
|---|---:|
| CE / RST | GPIO17 |
| SCLK | GPIO16 |
| IO / DAT | GPIO4 |

### Реле управления движением и технологией

Все реле в коде работают как **ACTIVE-HIGH**: `HIGH` — включить, `LOW` — выключить.

| Реле | Назначение | GPIO |
|---|---|---:|
| `REL_X_FWD` | движение X вперёд | GPIO19 |
| `REL_X_REV` | движение X назад | GPIO18 |
| `REL_Z_UP` | подъём Z | GPIO5 |
| `REL_Z_DOWN` | опускание Z | GPIO23 |
| `REL_SPIN` | вращение / барабан | GPIO15 |
| `REL_FAN` | вентилятор / сушка | GPIO2 |

### Концевики и безопасность

| Сигнал | Назначение | GPIO | Режим |
|---|---|---:|---|
| `SW_Z_TOP` | верхний концевик Z | GPIO0 | `INPUT_PULLUP` |
| `SW_Z_BOTTOM` | нижний концевик Z | GPIO13 | `INPUT_PULLUP` |
| `PIN_ESTOP` | аварийный стоп | GPIO26 | `INPUT_PULLUP` |
| `BTN_START` | физический старт | GPIO13 | `INPUT_PULLUP` |

⚠️ **Важно:** в текущей версии кода `SW_Z_BOTTOM` и `BTN_START` назначены на один и тот же GPIO13. Для реального щита это нужно развести на разные пины, иначе нижний концевик и кнопка старта будут конфликтовать.

⚠️ **GPIO0** является boot-strapping пином ESP32. Если верхний концевик притянет GPIO0 к неправильному уровню при включении, ESP32 может уйти в режим прошивки. Для промышленной схемы лучше перенести `SW_Z_TOP` на другой свободный GPIO.

### PN532 по оси X

PN532 для разметки ванн и сервисных точек X подключён как SPI-считыватель.

| PN532 X | GPIO ESP32 |
|---|---:|
| SCK | GPIO25 |
| MISO | GPIO39 |
| MOSI | GPIO27 |
| SS / CS | GPIO14 |

### PN532 по оси Z

PN532 для уровней Z подключён через `HardwareSerial(2)`.

| PN532 Z | GPIO ESP32 |
|---|---:|
| TX PN532 → RX ESP32 | GPIO36 |
| RX PN532 ← TX ESP32 | GPIO33 |
| RESET | 255 / не используется |

Примечание: GPIO36 — входной пин ESP32, поэтому он подходит только для RX.

### Энкодер

| Энкодер | GPIO ESP32 |
|---|---:|
| A | GPIO34 |
| B | GPIO35 |
| SW | GPIO32 |

Примечание: GPIO34 и GPIO35 — только входы и не имеют внутренних pull-up/pull-down. Для стабильной работы энкодера нужны внешние подтяжки или модуль энкодера с уже установленными резисторами.

### Управление циклом

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/status` | получить полный статус контроллера |
| `POST` | `/start` | запустить активный рецепт |
| `POST` | `/stop` | остановить цикл / запросить остановку |

### Рецепты

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/routes_list` | список рецептов в NVS |
| `GET` | `/route_get?id=N` | получить рецепт по ID |
| `POST` | `/route_save?id=N` | сохранить рецепт по ID |
| `POST` | `/route_apply?id=N` | сделать рецепт активным |
| `DELETE` | `/route_delete?id=N` | удалить рецепт |

    "spin": true,
    "fan": true

  {
    "bath": 2,
    "z_level_down": 3,
    "z_down_timeout_s": 10,
    "hold_s": 45,
    "z_level_up": 0,
    "z_up_timeout_s": 10,
    "dry_s": 10,

## 11. Состояния автомата процесса

В контроллере используется конечный автомат:

| Код | Состояние | Описание |
|---:|---|---|
| 0 | `PS_IDLE` | ожидание |
| 1 | `PS_HOMING` | поиск стартовой точки |
| 2 | `PS_MOVE_X` | движение к нужной ванне |
| 3 | `PS_LOWER_Z` | опускание подвеса |
| 4 | `PS_HOLD` | выдержка в ванне |
| 5 | `PS_RAISE_Z` | подъём подвеса |
| 6 | `PS_DRY` | сушка |
| 7 | `PS_NEXT_STEP` | переход к следующему шагу |
| 8 | `PS_RETURN_HOME` | возврат домой |
| 9 | `PS_ERROR` | ошибка / авария |
| 10 | `PS_LEARN_BATHS` | автообучение ванн |

## 12. Порядок первого запуска

1. Собрать силовую часть и проверить питание ESP32 отдельно от реле.
2. Прошить проект через PlatformIO.
3. Открыть Serial Monitor `115200`.
4. Подключиться к Wi-Fi `GalvaControl`.
5. Открыть `http://192.168.4.1/`.
6. Проверить `/status`: должны отображаться статус, готовность считывателей и состояние NVS.
7. Через `/baths_ui` или `/baths_autolearn_ui` привязать RFID-метки:
   - старт X;
   - конец X;
   - рабочие ванны;
   - старт/конец Z;
   - уровни Z.
8. Создать рецепт через `/routes_ui`.
9. Сохранить рецепт в NVS.
10. Сделать рецепт активным.
11. Проверить движение без нагрузки.
12. Проверить аварийный стоп.
13. Только после этого подключать реальную технологическую нагрузку.

## 13. Важные замечания по безопасности

⚠️ Проект управляет реле и приводами. Для реальной гальванической линии обязательно нужны:

- аппаратный аварийный стоп, разрывающий питание приводов;
- защита от одновременного включения противоположных направлений X и Z на уровне схемы;
- концевики, подключённые через надёжную промышленную схему;
- опторазвязка реле;
- защита ESP32 от наводок и выбросов;
- отдельное питание силовой части и логики;
- предохранители;
- ручной режим обслуживания;
- проверка всех GPIO на конфликты перед монтажом.

Программная защита в коде не заменяет аппаратную защиту.

## 16. Быстрая диагностика

### ESP32 не загружается после подключения концевика

Проверить GPIO0. Если он притянут к неправильному уровню во время старта, ESP32 может входить в bootloader.

### Не работает энкодер

GPIO34/GPIO35 не имеют внутренних подтяжек. Нужны внешние pull-up/pull-down.

### Рецепт не стартует

Проверить:

- выбран ли активный рецепт;
- есть ли шаги в рецепте;
- настроена ли стартовая точка;
- привязаны ли ванны, на которые ссылается рецепт;
- готовы ли PN532-считыватели;
- не активен ли аварийный стоп.

### PN532 не видит метки

Проверить:

- питание PN532;
- общий GND с ESP32;
- правильный режим интерфейса PN532: SPI для X, UART для Z;
- расстояние до метки;
- наличие металлических помех рядом с антенной.

## 17. Краткая схема логики рецепта

```text
START
  ↓
HOMING: найти стартовую точку X
  ↓
MOVE_X: доехать до ванны из шага
  ↓
LOWER_Z: опустить до z_level_down
  ↓
HOLD: выдержка, опционально SPIN
  ↓
RAISE_Z: поднять до z_level_up
  ↓
DRY: сушка, опционально FAN
  ↓
NEXT_STEP
  ↓
если шаги закончились → RETURN_HOME
  ↓
IDLE
```
